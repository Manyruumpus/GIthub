## Pingala Dashboard Replica

Open `index.html` in any modern web browser to view the UI replica of the Pingala dashboard shown in the reference image. The project uses CDN links for Bootstrap 5 and Font Awesome, so no additional setup or build steps are required.

### Files

- `index.html` – main HTML structure.
- `styles.css` – custom styles to match the screenshot.

Feel free to tweak the styles or structure as needed.
